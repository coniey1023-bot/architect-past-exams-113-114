# 第五堂課：建築師考古題

本資料夾整理考選部 113、114 年「專門職業及技術人員高等考試建築師」考畢試題索引。

## 使用方式

- 開啟 index.html，可依年度篩選或搜尋科目。
- 「開啟試題」連結至考選部官方 PDF。
- 營建法規與實務、建築結構、建築構造與施工、建築環境控制另列標準答案與更正答案。
